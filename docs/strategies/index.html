On this page

Strategy documentation ​

FD Cal documents strategy behaviour separately for each simulation objective.

Scoped Range ​

The supported strategies optimise the selected start and end dates. Their current objective, trade-offs and optimality limits are summarised in the strategy guide.

Technical references ​

  • Greedy — local SPLIT/CONSOLIDATE/CARRY decisions and option-selection rules.
  • GSS — recursive scoped planning, liquidity-aware waiting and candidate ordering.
  • Absolute R — exhaustive scoped branch-and-bound search and optimality proof conditions.
  • Absolute R+ — bounded scoped search, controls and search diagnostics.

Benchmark ​

  • Scoped Range benchmark — measured net-interest response to horizon, capital, account/bank diversity, inflows and eFD eligibility.

Goal ​

Status: Under development — no benchmark data available yet.

Goal mode is disabled and is not currently user-selectable. The intended first Goal optimiser is Absolute R; the other three strategies remain Scoped Range only.

  • Goal-mode rework plan — architecture, implementation phases and release gates.
