Optimisation strategies

Strategy names in the web tool are intentionally kept concise. These guides explain the decision model and trade-offs behind each option.

GAML

Bounded beam search that explores multiple promising plans while controlling search cost.

GSS

Recursive goal-seeking strategy that evaluates SPLIT and CONSOLIDATE plans and uses interim investments while preserving future goal liquidity.

Fast local decision-making strategy. Useful as a baseline, without a global optimality guarantee.
