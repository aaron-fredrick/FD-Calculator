Bank accounts

Add the savings accounts used by this FD plan. For each account, the starting balance means only the amount allocated to FD investing—not the account’s full bank balance. For example, if the bank account holds LKR 100,000 but you want this plan to invest LKR 20,000, enter LKR 20,000.
